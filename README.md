🔗 **線上使用**：https://steven4dev.github.io/osh-quiz/

## 功能特色

- **入口頁**：顯示各題庫的作答進度與錯題數
- **題庫切換**：在橫幅直接切換題庫或回首頁
- **🔢 金庫密碼**：單獨篩選含數值、單位的題目，考前快速複習數字
- **⭐ 我的錯題本**：答錯自動收錄，可專項複習
- **進度與正確率**：顯示已作答題數、完成百分比與正確率
- **預估完成時間與時鐘**：點時鐘可切換全螢幕
- **顯示答案**：一次顯示所有正確答案，不計入統計
- **關鍵字搜尋**：即時篩題
- **工具列收折**：收起篩選與搜尋，多留答題空間，換題庫也會記住
- **匯出、匯入**：把作答紀錄帶到其他裝置
- **深色、淺色模式**：自動偵測系統偏好，可手動切換
- **響應式設計**：支援桌機雙欄與手機單欄

作答紀錄只存在目前的瀏覽器（localStorage）。

## 本機預覽

頁面之間的連結使用 `/osh-quiz/` 開頭的路徑，請在 repo 的上一層資料夾啟動伺服器：

```bash
python -m http.server 8000
```

再開啟 http://localhost:8000/osh-quiz/ 。此時資料夾名稱必須是 `osh-quiz`。

## 維護注意事項

**線上頁面才是最新版。** 各頁已直接更新橫幅、導覽與修正，repo 內的建置腳本（`build_html.py`、`113/build_html.py`、`kyso/build_html.py`）尚未同步。重新執行會產生舊版頁面，也會覆蓋題庫資料以外的修改，更新前請先確認。

每次發布都會更新頁面右下角的版本號，格式為 `vYYMMDD.NN`，`NN` 是當天第幾次發布。
